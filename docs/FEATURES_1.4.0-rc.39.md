# YOSOI NOTE 1.4.0-rc.39

デスクトップのプレビューを実際の表示領域にフィットさせ、固定縮小上限と二重の余白計算を廃止。ヘッダー・ツールバー等の余白を整理し、中央画像に使える高さを拡大。「拡大表示」で編集欄を隠し、Escまたは「編集に戻る」で復帰。150%・200%の表示倍率も追加。表示だけの変更で、写真の位置・保存データ・PNGの出力寸法は変えません。

先行更新d8b3f5cのRender版Analytics廃止と厳格化CSPを保持。共有ビルドでもRenderでは過去の同意状態にかかわらずAnalyticsを起動せず、Cloudflare側の既存の任意計測設定を維持します。
