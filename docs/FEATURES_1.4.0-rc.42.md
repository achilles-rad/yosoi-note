# rc.42 — 表紙パーツの組み合わせ

表紙編集のテンプレートで「シリーズから選ぶ／パーツで組み合わせる」を切替。
背景は既存のCOLOR STUDIO、誌名・見出し・前景装飾は個別画像を読み込む。
各パーツは表示、写真との前後、移動、拡縮、回転、不透明度を独立して調整し、保存・ZIP・PNGに含める。
既存の一体型文字・装飾は従来どおり使用可能。個別パーツ追加時は一体型を保持して非表示。表紙シリーズ再選択時は個別パーツを保持して非表示にする。
既存画像から誌名・見出し・装飾を自動分離したと扱わない。分離素材がない場合は利用者が個別画像を読み込む。PSD直接取り込み・自由文字は別工程。
ファイル数上限は6写真＋12アセット＋背景2層＋3パーツの23画像。20MB/画像・100MB総量・6,000万画素・ZIP実展開サイズの制限は保持。

透過パーツは選択中だけ操作対象にし、Escで選択を解除できる。未選択パーツの透明余白が写真のドラッグを遮らないことをブラウザで確認。
