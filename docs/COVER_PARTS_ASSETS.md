# 表紙パーツ素材の準備

表紙編集 → テンプレート → パーツで組み合わせる、から個別に読み込みます。

|種類|ファイル名の例|形式・用途|
|---|---|---|
|背景|background.png|背景のみ。誌名や見出しを焼き込まない|
|誌名|masthead.png|誌名だけを描いた透過PNG|
|見出し|headlines.png|見出しだけを描いた透過PNG。複数の見出しを1枚にまとめてもよい|
|前景装飾|foreground.png|枠・花・光・帯などの透過PNG|

縦2:3の表紙なら、4枚とも1024×1536 pxなど同じサイズで用意します。透明な余白も残し、書き出し時に内容の周囲だけへ切り詰めないでください。元の位置関係を保ったまま組み合わせやすくなります。異なるサイズ・比率の画像も読み込めますが、位置・大きさの調整が必要になる場合があります。

PSDで制作する場合も、背景・誌名・見出し・前景装飾を別レイヤーで管理し、アプリに読み込むときはそれぞれ画像へ書き出します。現段階ではPSD自体を直接読み込む機能はありません。PNGの文字は画像として配置するため、文言の修正は元の制作ファイルで行ってください。アプリの既存の見出し入力は引き続き利用できます。

誌名・見出し・前景装飾は、アプリ内で表示、位置、大きさ、回転、不透明度、写真との前後を調整できます。色を変える場合は素材側で用意します。背景・アプリ内の文字配色はCOLOR STUDIOで調整します。

旧表紙シリーズの文字と装飾は一体型です。誌名だけを自動で取り出した素材としては扱いません。個別パーツを読み込むと一体型の文字・装飾を保持して非表示にし、シリーズを選び直すと個別パーツを保持して非表示にします。レイヤー画面から選択・再表示できます。

画像は1枚20MB、合計100MB、合計6,000万画素まで。読み込んだ素材と編集内容はブラウザ保存・ZIPバックアップ・PNG出力に含まれます。

今後プリセットにする際は、シリーズ名・アバター名・素材名と4枚の対応関係をそろえて登録できる構成にします。現時点で分離済み素材のプリセットは追加していません。
