# 1.4.0-rc.43 — ALTERWEAR Rurune 増刊号

5種類をCOLOR STUDIOの独立した増刊号フォルダーへ追加。4分類PNGを同時に読み込み、写真の前後・表示・位置・サイズを個別に調整できます。初期設定は縦2:3、タイトル・クレジット・アセット非表示、写真は文字の背面。保存・ZIP・PNGに対応。既存60表紙を保持。

誌名・見出しは画像で、文章の直接編集はできません。背景の水面・宝石等は背景と一体です。PSD直接読み込み機能は追加していません。原本は変更せず、同梱PNGを分類ごとに合成。分類合成と完成PNGとの差分を計測。結果は非公開の検証記録に保存。PSD解析にレイヤーマスク領域のパディング警告あり。Photoshop実機の互換性は未検証。
