# 1.4.0-rc.40 — 編集画面の整理

- 左「素材とレイアウト」、右「配色と仕上げ」と用途を明示。選択中のタブで扱える設定を表示。
- レイアウトは出力モード・比率・全体配置を基本設定として先に表示。写真プリセット、アセットの形・フレーム・サイズは目的別に開閉。
- COLOR STUDIOではおすすめ配色を先に表示し、独自の色調整を折りたたみ。
- 長い説明は補足・使い方へ集約。全設定表示では詳細設定も開く。
- 中央プレビューの固定・拡大・左右の独立スクロール、保存形式と描画内容は維持。
- Render配信版の計測停止、既存バックエンドを維持。

実施した検証と公開結果はリリース記録に別途記載。Windows・スマートフォン実機の確認は未実施。
