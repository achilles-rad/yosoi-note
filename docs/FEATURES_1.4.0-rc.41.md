# rc.41 — アセット編集と表紙編集

同じアプリ内で編集する目的を切り替え、中央プレビュー・保存・PNG出力を共通化。
- アセット編集は従来の写真／レイアウト／文字／アセット。
- 表紙編集はテンプレート／写真／文字／レイヤー。テンプレートからCOLOR STUDIOのシリーズを直接開く。
- レイヤーで既存の表紙文字の前後、見出し・クレジット、アセット一覧の表示を調整。
- 切り替え自体は画像内容や保存データを変更しない。全設定表示も選択モードの範囲内。
- スマホでもプレビューを保持し、表紙用メニューを表示。

今回の対象は画面分離と既存機能の整理。PSD直接取り込み、自由文字の追加、アバター別分類、分離文字を非表示にするモードは後続工程。既存の背景文字の近似分離に関する注意を保持。
